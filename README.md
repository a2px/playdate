# Playdate

Find a fair place to meet a friend. Enter both addresses, pick driving or public
transit, and Playdate suggests well-known spots that take you both about the same
time to reach, with links to find places to eat and things to do there.

Live at https://a2px.github.io/playdate/

Runs entirely in your browser using free, open map services: OpenStreetMap
(map and address lookup), OSRM (driving times), Transitous (public transit times)
and Wikidata / Wikipedia (places and their descriptions).
